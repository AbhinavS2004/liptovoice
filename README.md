# liptovoice

REVOCALIZE is an AI-powered Visual Speech Recognition (VSR) system that converts lip movements into spoken output in real time. Unlike traditional speech recognition systems that rely on audio signals, REVOCALIZE interprets speech visually by analyzing lip movements captured through a camera.

The system combines Computer Vision, Deep Learning, Natural Language Processing, and Text-to-Speech technologies to create a complete pipeline capable of generating meaningful voice output from silent visual input.
